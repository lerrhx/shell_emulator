# Эмулятор оболочки ОС (Вариант 31)

## Описание
Консольный эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом (GUI).
Реализован на языке Python с использованием библиотеки Tkinter.

## Возможности
- Загрузка виртуальной файловой системы (VFS) из CSV-файла.
- Команды: `ls`, `cd`, `tac`, `find`, `rmdir`, `exit`, `conf-dump`, `vfs-init`.
- Поддержка переменных окружения (например, `$HOME`).
- Обработка ошибок (неизвестная команда, неверный путь и т.д.).
- Выполнение стартового скрипта с комментариями.

## Параметры командной строки
- `--vfs <путь>` — путь к CSV-файлу с VFS.
- `--script <путь>` — путь к стартовому скрипту.

## Пример запуска
```bash
python my_shell.py --vfs test_vfs.csv --script test_script.txt
